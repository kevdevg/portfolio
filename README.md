# Kevin Guevara — Neural Capabilities Architecture

Interactive scroll-driven portfolio built with **React 19**, **Vite 8**, and a **3D Parametric Synaptic Brain Engine (`<canvas>`)** over Dark Obsidian (`#06080D`).

## Architecture

- **3D Bioluminescent Connectome (`NeuralBrainCanvas`)**: Parametric two-hemisphere cortical topology with curved Bézier axonal tracts, travelling action potentials, scroll-coupled 3D camera orientation across four functional regions, and touch/pointer synaptic excitation.
- **Capabilities-First Continuous Journey (`MindJourney`)**: Zero-clutter bilingual (`EN / ES`) narrative highlighting end-to-end systems, native AI, programmable platforms, and sovereign infrastructure.
